# Student Performance Intelligence System

A beginner-friendly Python project for analyzing student performance data using NumPy-based data operations. It is designed to help students and educators understand marks distribution, subject-wise averages, positional rankings, and low-performance cases.

## Overview

This project focuses on exploring sample student marks and deriving useful insights such as:

- Subject-wise average marks
- Student performance ranking
- Identification of students below a threshold
- Basic data analysis with NumPy

## Features

- Analyze student marks across multiple subjects
- Compute averages efficiently
- Rank students based on total performance
- Highlight students below a defined score threshold
- Simple and educational structure for beginners

## Tech Stack

- Python
- NumPy
- Jupyter Notebook (optional for experimentation)

## Getting Started

1. Clone the repository
2. Open the project in your preferred Python environment
3. Install the required dependencies:

```bash
python3 -m pip install -r requirements.txt
```

4. Run the analysis script or notebook:

```bash
python3 scripts/analyze_student_performance.py
```

or open the notebook in `notebooks/student_performance_analysis.ipynb`.

## Example Use Cases

- Evaluate class performance by subject
- Identify students who need extra support
- Compare individual student scores against class averages
- Use as a learning project for data analysis fundamentals
